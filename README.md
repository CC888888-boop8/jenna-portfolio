# Jenna Portfolio｜部署版

這是可直接部署的靜態網站，入口檔為 `index.html`。將整個資料夾（保留 `assets/` 結構）上傳至 GitHub Pages、Netlify、Vercel Static 或一般網站主機的公開目錄即可。

本版本保留原版首頁視差、捲動進度導覽、手機導覽、進場動畫與作品放大互動；作品區使用本地化素材，不依賴雲端硬碟或外部影片連結。

作品區：

- 廣告策略與成效洞察：精選 6 個跨產業案例，各自一張分析圖，點擊可放大。
- 動態作品：6 支本地 10 秒預覽，以一主五輔的編排呈現，可一鍵全部暫停。
- 平面作品：4 件跨題材靜態視覺，以主視覺、側欄與橫幅建立閱讀層級。
- 動畫與主視覺：動畫／實拍合成 3 支、動態主視覺 3 支，6 件皆可直接預覽。
- 分鏡腳本：「挺立」完整分鏡選輯，以及兩件輔助案例。

影片預覽已移除音訊、設定為 H.264 MP4、每支約 10 秒，適合直接放在作品集頁面中。
